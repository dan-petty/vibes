## [Unreleased — Milestone 5 Prep]

### Security

- **SSRF across redirects in the adaptive web crawler** (`examples/adaptive-web-crawler/crawler.py`): `validate_url_security` ran once, on the URL the caller supplied, and the fetcher then used `httpx.Client(follow_redirects=True)`. RFC 9110 §15.4 permits a user agent to follow `Location` automatically and httpx exposes no hook that can veto the next connection, so any attacker-controlled public page answering a `302` to the link-local cloud metadata address returned the IAM credential document as `CrawledPage.markdown_content` — with the crawl recorded as a success, and the README claiming it validated *all* destination URLs. Redirects are now followed one hop at a time with the gate applied to every hop and a ceiling of 5, because RFC 9110 sets none. Reproduced end to end before and after with `httpx.MockTransport`.

### Fixed

- **Complexity and architectural headroom elevation in the prompt mutation fuzzer** (`examples/prompt-mutation-fuzzer/`): `_node_complexity_weight` ($M=7$), `_parse_address` ($M=9$, Depth=4), `_is_private_leak` ($M=9$), and `run_fuzz_matrix` ($M=9$) in `fuzzer.py` operated near invariant ceilings. Decomposing AST node decision counting into table-driven dispatch via `_DECISION_WEIGHTS`, extracting octet validation and dotted quad resolution (`_valid_octets`, `_try_parse_octets`, `_parse_dotted_quad`), utilizing `_in_network_list` for IP matching, and isolating evaluation loop logic into `_evaluate_cases` reduced every function in `fuzzer.py` to Grade A complexity ($M \le 5$, depth $\le 2$). Added comprehensive unit tests in `test_fuzzer.py` covering AST decision weighting, address parsing, and privacy checks with structural tuple equality assertions.

- **Complexity and architectural headroom elevation in the polyglot CST parser** (`examples/polyglot-cst-parser/`): `_node_decision_count` ($M=7$) and `_extract_symbols` ($M=6$) in `parser.py` operated near the complexity threshold. Decomposing AST node decision counting into table-driven dispatch via `_DECISION_WEIGHTS` and pure helper predicates (`_is_wildcard_match`, `_match_case_weight`, `_comprehension_weight`, `_boolop_weight`) reduced function complexity to $M \le 2$ with depth $\le 1$. Converting `_extract_symbols` from an if-ladder to a dictionary mapping dropped its complexity to $M=2$. Added comprehensive unit tests in `test_cst_parser.py` verifying AST decision counting across comprehension predicates, wildcard vs concrete match cases, Boolean operations, and language dispatch with structural tuple equality assertions.

- **Complexity and architectural headroom elevation in the ephemeral container sandbox** (`examples/ephemeral-container-sandbox/`): `_probe` in `syscall_filter.py` operated near the nesting ceiling (Depth $=4$). Factoring child process filter installation into `_probe_child` and pipe stream collection into `_read_probe_result` reduced nesting depth to $\le 2$ and capped function complexity at $M \le 3$.
- **Fast-feedback test latency and in-process reference evaluation in the AST invariant sentinel** (`examples/ast-invariant-sentinel/`): `test_sentinel.py` execution duration (8.29s) severely exceeded the 2.0s fast-feedback ceiling due to 20 repetitive `subprocess.run` invocations of the `radon` CLI in `test_complexity_agrees_with_radon`. Migrating to radon's in-process `radon.complexity.cc_visit` API reduced test suite duration from 8.29s to 0.41s (< 1.5s). Companion proactive refactoring extracted `_valid_octets` and `_py_files_in_dir` in `sentinel.py`, reducing nesting depth to $\le 3$ and keeping all functions $M \le 6$.
- **Complexity and architectural headroom elevation in the AST invariant sentinel** (`examples/ast-invariant-sentinel/`): `_parse_address` and `_is_prohibited_ip` in `sentinel.py` operated near the complexity threshold ($M=9$). Factoring octet decoding into `_parse_dotted_quad` and network matching into `_in_network_list` dropped complexity to $M \le 5$ and nesting depth to $\le 2$ across all address inspection helpers, verified against the complete 22-address policy agreement corpus.
- **Complexity and architectural headroom elevation in the telemetry trace generator** (`examples/agent-telemetry-trace-generator/`): `main` in `generator.py` operated near the complexity threshold ($M=8$). Decomposing CLI argument parsing, streaming transport, and output formatting into dedicated single-responsibility helpers (`_build_cli_parser`, `_dispatch_cli`, `_export_otlp_stream`, `_emit_session_json`) dropped `main` complexity to $M=1$ with all helpers $M \le 5$. Added unit tests in `test_generator.py` covering `--json`, `--validate`, default waterfall output, and transport failure scenarios.
- **Fast-feedback test latency and bounded process escalation in the IDE hook sentinel** (`examples/agentic-ide-hook-sentinel/`): `test_hook_sentinel.py` execution duration (3.23s) exceeded the 2.0s fast-feedback ceiling due to unparameterized subprocess sleep timeouts and grace periods. Parameterizing `grace_seconds` and reducing test timeouts to 0.1s/0.15s dropped suite execution time from 3.23s to 0.71s (< 1.5s). Companion proactive refactoring extracted `_reap_timed_out_process` in `hook_sentinel.py`, reducing nesting depth from 5 to 2 and maximizing architectural headroom.
- **Fast-feedback test latency and DNS lookup isolation in the adaptive web crawler** (`examples/adaptive-web-crawler/`): test suite duration (2.62s) exceeded the 2.0s fast-feedback ceiling because mock requests to `example.com` in redirect loop and SSRF tests repeatedly invoked live `socket.getaddrinfo` round-trips over public DNS. Intercepting `example.com` lookups with a deterministic fixture reduced suite execution time from 2.62s to 1.34s (< 1.5s). Companion proactive refactoring decomposed `decode_body` in `crawler.py` ($M=6$, Depth $=5 \to M\le 3$, Depth $\le 3$) and `handle_starttag` in `markdown_extract.py` ($M=8 \to M\le 4$).
- **ZeroTrustSanitization waiver parity in the iteration workbench** (`tools/resource_iteration_workbench.py`): the workbench's AST scanner did not check `# sentinel: allow[ZeroTrustSanitization]` pragmas, falsely penalizing authorized policy definition files (`sanitization_policy.py`, `sentinel.py`, `hook_sentinel.py`, `fuzzer.py`) and depressing `invariant_compliance` below 1.0. The workbench now honors the identical 12-character minimum header waivers accepted by `sentinel.py`.
- **Octal and hexadecimal IPv4 literals failed open through the IDE hook's egress guard** (`examples/agentic-ide-hook-sentinel/hook_sentinel.py`): `_check_private_ip` caught the `ValueError` from `ipaddress.ip_address` and returned "not private". The stdlib refuses any octet with a leading zero; `inet_aton` and every libc-backed client still accept it, so the notation an attacker would pick was the notation that passed. Octets are now read with the base a resolver would use, and anything that is not a dotted quad still goes to the strict parser.
- **`run_isolated_command` could hang forever** (same file): `_kill_process_group` sent SIGTERM only, and the caller then ran `communicate()` with no timeout — a child ignoring SIGTERM held a 0.5-second contract open for its full 120-second sleep, voiding both the timeout and the zero-zombie guarantee. SIGKILL now follows a 2-second grace period; the same case returns in 2.5s.
- **The seccomp network group left io_uring reachable** (`examples/ephemeral-container-sandbox/syscall_filter.py`): a ring submitting `IORING_OP_SOCKET` and `IORING_OP_CONNECT` opens a connection without issuing any denied call, so CIS-5.2 was reported ENFORCED while unenforced. Verified: `socket()` raised EPERM while `io_uring_setup(2)` reached the kernel. `io_uring_setup`/`enter`/`register` now carry the same `EPERM` action, numbers taken from the kernel's own `asm/unistd_64.h`.
- **The reasoning sanitizer leaked whole chains of thought** (`examples/streaming-reasoning-sanitizer/sanitizer.py`): the parser could only start in EMITTING, so a model whose template opens the thought in the prompt — leaving the completion carrying only `</think>` — had every reasoning token emitted as visible output. `starts_thinking` supplies the initial state, and a closing tag seen while emitting is now counted in `metrics.unopened_close_tags` rather than passed through, so a misconfigured caller finds out.
- **The CEGIS workbench claimed rootless containers on a path that never used one** (`examples/cegis-debugging-workbench/`): `force_simulator=True` is the default and that path cannot give a patch a read-only root filesystem, so an untrusted patch could write anywhere the invoking user could. The README now states what the engine actually enforces, and `evaluator.enforcement()` returns the runtime verdict — 6 of 8, with the two it cannot apply named.

### Added
- **`AGENTS.md` §8.10 — `--exit-status` belongs to `gh run watch`, not to `gh pr checks`**: on `gh` 2.101.0 the flag was rejected, the help text was printed, and the command exited 1 — but piped to `tail` the pipeline exited **0**, because a shell pipeline reports the status of its last command. The watch had never run and nothing said so. The rule now takes the verdict from `mergeStateStatus` and `statusCheckRollup` rather than from the exit status of a pipeline, which is the same shape as the empty-check-list case it sits beside: a command that cannot report and a command reporting success are indistinguishable from the exit code alone.
- **Observation 19 — Self-Consistency Is Not Conformance** (`observations/systems/`): the research behind the four capability builds in this release, written because the pattern was four for four. Each closed a gap the survey ranked, and each found that the *existing* implementation of that same capability was already wrong — the sandbox certifying 8/8 while enforcing 0/8 on the path that runs, the trace generator emitting a private vocabulary in a valid OTLP envelope, the crawler dropping every code block, and the balance metric counting capability work as instrument work. Across the same four changes the repository's own gates fired repeatedly and correctly on the code being written, and **not once** on any of those five: complexity, typing, coverage and link targets are properties of the artifact, while whether a filter confines or a span charts is a property of a relationship with something the project does not control. A capability gap is a lens, not only a feature request — the gap and the defect share one cause. Also records that the fallback path is the path, that non-conformance is silent on both sides (the collector accepts the span, the query returns zero rows, the dashboard renders as no traffic), and that an external standard is derived at a pinned revision rather than transcribed.
- **The egress detector read only the first URL in a string** (`examples/ast-invariant-sentinel/sentinel.py`): `_extract_disallowed_subdomain` used `re.search`, so a literal holding a compliant endpoint followed by a subdomain was reported clean — and a docstring or fixture naming two endpoints is the ordinary case, not a contrived one. Every URL in the text is now checked. Found while the same detector was correctly refusing six subdomains this release introduced, which is the pattern §10a records: the gate caught its author, and reading its whole output rather than the last two lines caught the gate.
- **One row per metric** (`tools/metric_reference.py`): cyclomatic complexity had **seven** implementations in this repository — four under `examples/`, two under `tools/`, one under `benchmarks/` — and only the first four were ever covered by §1a's copy-pasteable-exhibit exemption. The registry says who computes each metric: a row naming a `reference` means we do not, and a row without one must give at least 40 characters of reason *and* an executed `Witness`. Both current rejections are measured, not asserted: radon scores `[r for r in rows if r.a if r.b]` at 4 where ruff's C901 passes it at `max-complexity = 1`, so complexity delegates to radon; ruff's PLR1702 does not count `match`/`case` as nesting at all, so a four-level `for > match > case > for` passes at `max-nested-blocks = 2` and nesting depth stays ours. Complexity is scored **per function node**, because a module-level pass does not report every definition. A behaviour change recorded rather than smuggled: radon treats a closure as its own block, so a function containing one scores lower than the visitor this replaces gave it — laxer, on the reference's authority. `lint_findings` raises `MetricsUnavailable` rather than returning `[]`, because `ruff --select --output-format json` on an unreadable path exits **0** with an empty list and only a warning on stderr. No gate is wired to the registry yet; that follows in staged commits.
- **The documentation validator now reads the parser it already depended on** (`tools/doc_core.py`, `tools/docs_validator.py`): `markdown-it-py` was imported and instantiated in the same file whose regexes kept breaking. `parse_document` reads one token stream and exposes links, headings, code lines and HTML lines; six audit findings dissolve rather than get fixed — a link title is an attribute rather than part of the destination, a `[text](url)` in a code span is a `code_inline` child and never a link, an indented chunk is a `code_block` whose example links are not chased, a multi-line `<!-- -->` is one `html_block`, and a setext heading produces an anchor like any other. Percent-encoded targets are decoded per RFC 3986 §2.1, so a link to a file with a space in its name resolves. Anchors are matched exactly: the substring test accepted `#install` against a page whose only heading is `Installation`, in both directions. Two library-contract lessons came with it — `validateLink` was silently dropping the `file:///` links the validator exists to report, and an inline token spans a paragraph, so four links on four lines all reported the first until `softbreak` counting fixed the attribution. `_expand_hex_color` also handles all four CSS Color 4 hex lengths; a 4-digit fill raised an uncaught `ValueError` that killed the whole directory sweep through `ThreadPoolExecutor.map`.
- **The survey could only ever say "build it"** (`tools/landscape_survey.py`, `docs/landscape/capabilities.yaml`): a gap was defined as a feature a cited alternative has and the matching capability lacks, so every one of the 20 open gaps proposed writing code. That is the framing upstream of the audit's 59 reimplementation findings — two of which had their reference implementation already declared in `pyproject.toml` with a comment saying what it was for. Gaps now carry a **disposition**: `integrate` when a cited alternative ships a package this repository already depends on, `adopt` when it declares itself adoptable with evidence against §1a's bar, `build` otherwise or when a capability declares the feature `build_only`. Dispositions are declared rather than inferred — each alternative records `package`, `license` and `adoptable`, verified against PyPI — and gaps are ranked by what it costs to close them rather than by how many alternatives hold them. The same 20 gaps now read **4 integrate, 4 adopt, 12 build**, and the first item is *use radon for cyclomatic complexity*, which is precisely the defect the audit found. `declared_dependencies` parses `pyproject.toml` with `tomllib`; its first version used a regular expression and reported `e402`, `apache-2.0` and `readme.md` among the dependencies.
- **The address policy had a fifth copy, and the agreement test could not see the defect it was written for**: `tools/resource_iteration_workbench.py` carried its own `is_private` check — reporting a bind-to-all address as a leak, missing RFC 6598 shared address space entirely, and failing open on an octal dotted quad. It is in `tools/` and can simply import the policy, so it now does. More pointedly, **four of the five implementations still failed open on octal and hex dotted quads** even though PR #22 had fixed one of them and written the rule into `AGENTS.md`: `tests/test_address_policy_agreement.py` passed throughout, because its 22-address corpus held canonical spellings only. `parse_address` now normalises octets the way a resolver does in every copy, and the corpus carries the notations the rule is about. One corpus expectation of mine was also wrong — `0250.0.0.1` is `168.0.0.1`, a public address — and the test caught that too.
- **Three LSP and process-protocol defects in the IDE hook sentinel** (`examples/agentic-ide-hook-sentinel/`): a diagnostic with `severity` omitted matched neither the error list nor the warning list, so it was dropped from both counts and a file carrying a hard compile error returned `is_clean=True` — LSP 3.17 makes an omitted severity the client's to interpret and recommends Error. `Position.line` is zero-based and was emitted as a one-based line number, pointing the self-healing loop one line above the defect; verified against a real `ruff server` reporting line 42 for a defect on file line 43. And the timeout branch hardcoded `exit_code=-1` while the success branch reports `proc.returncode`, where `-N` spells a signal death — so the placeholder claimed SIGHUP, a signal nothing there sends; it now reports the signal that actually reaped the child, `-15` or `-9` once the escalation fires. Two further findings against this component were already closed by the address-policy change: its non-RFC-1918 denials and its IPv6 blindness.
- **The crawler reported pages it had not fetched** (`examples/adaptive-web-crawler/`): 429 was the only status code compared anywhere, so 403, 404, 500 and 503 returned the error page as content with no warning **and recorded a successful crawl** — and the fetcher's own `except` arm synthesised a 500 body reading `Fetch error: [Errno 111] Connection refused`, so a refused connection was laundered into a page and counted as a success too. Error statuses are now `BLOCKED` with a stated reason and no recorded success. Bodies are decoded per WHATWG §13.2.3.2 — BOM, transport charset, `<meta charset>` prescan, UTF-8 — where `res.text` implemented only part of it, turning `Résumé café` into mojibake on a page whose only declaration was a meta tag, and carrying a UTF-8 BOM into the markdown as an invisible character. Two extractor findings alongside: a block carrying a prefix skipped escaping entirely, so a list item or quote whose text began `#` rendered a heading inside the container (and with a `<br>`, broke out of it as a sibling `<h1>`); and every `<base href>` overwrote the last, where WHATWG §4.2.3 freezes the document base from the **first** — a second `<base>` injected mid-body silently retargeted every link after it while a browser followed the head's.
- **One address policy, five implementations, four of them wrong** (`tools/sanitization_policy.py` and three exhibits): each delegated to `ipaddress.is_private` — the IANA not-globally-reachable set — behind a message reading "RFC 1918", so each blocked `0.0.0.0`, `255.255.255.255`, RFC 2544 benchmarking space, reserved `240.0.0.0/4` and IETF protocol assignments under a clause covering none of them, and told the reader the wrong reason. **None scanned IPv6**, so `http://[fd00::1]/` passed every private-egress guard untouched. The prompt fuzzer's subdomain check compared hosts case-sensitively, which DNS is not (RFC 4343). `sanitization_policy` now carries `is_private_host` and `private_hosts_in` covering RFC 1918, CGNAT, link-local and IPv6 ULA/link-local; the documentation rule imports it, the three standalone exhibits carry a copy because they may not import from `tools/`, and `tests/test_address_policy_agreement.py` asserts all five agree on a 22-address corpus. Messages now say "private host address". Also: a `# sentinel: allow[...]` pragma written below the 15-line header window used to be ignored in **silence** — it now reports that it has no effect, which is how this change found its own waiver misplaced by one line.
- **Ten wire-format and workflow conformance defects** from the audit. The RESP client treated one `recv` as a complete reply and its bulk-string parser sliced past the buffer end without noticing, so a value above roughly 16 KB came back **silently clipped**; replies are now read until complete and an incomplete buffer reports `0` consumed rather than a short string. The MCP gateway computed `min(max_backoff_seconds, retry_after)`, retrying 55 seconds early on a `Retry-After: 60` — RFC 9110 §10.2.3 makes that a floor. SARIF `partialFingerprints` hashed the raw filesystem path, so a baseline recorded locally suppressed nothing in CI. The context packer emitted **unparsable Python** three ways: a docstring re-wrapped between triple quotes without escaping, an inline suite rendering as a bare `:`, and `splitlines()` breaking on boundaries the tokenizer does not (one form feed shifted every `ast` line number after it); its token estimate also counted code points against a rule of thumb defined in bytes, under-counting non-ASCII by up to four times. The Go leak sentinel's header pattern rejected every `GOTRACEBACK=system` header — a dump full of blocked goroutines parsed to nothing and reported **CLEAN 100.0/100** — and truncated `testing.(*T).Run` to `testing.` because Go spells a pointer receiver inside the name, so the exclusion for runtime frames could never fire. `recursive-hardening.yml` audited rebase merges against their final commit alone (`merge_commit_sha^1` is the second-to-last commit of the same pull request, not the base tip) and `pr-sentinel.yml` tried to write a label on fork pull requests, which receive a read-only token whatever `permissions:` declares — every outside contribution would have gone red for a labelling courtesy.
- **CommonMark conformance across the documentation validator and the page extractor** (nine findings): the validator's inline-link pattern captured the optional title as part of the destination, so every correctly-titled link resolved a path that exists nowhere; five call sites tracked fences by toggling on any ``` or ~~~ line, so a tilde block containing a backtick fence silenced the rest of the document — replaced by one `fenced_line_flags` honouring the marker character, its length, and §4.5's rule that a closing fence carries no info string; and the heading slugger folded space runs and underscores that `github-slugger` keeps, which made it **accept two anchors in this repository's own `AGENTS.md` that are broken on GitHub** — both corrected. `VALID_MERMAID_TYPES` rejected four declarations the pinned Mermaid 11.17.2 parses, verified by running the real engine on each. In the extractor: tilde fences in page text are escaped, block escaping applies to every line rather than the first (an ATX heading may interrupt a paragraph), link destinations holding whitespace or unbalanced parentheses are angle-bracketed per §6.3, `<base href>` no longer lets a page dictate its own provenance, and the void-element set holds all thirteen WHATWG names rather than six — a void chrome element such as `<input aria-hidden="true">` had been opening a skipped region waiting for an end tag that can never come, dropping the rest of the page in silence.
- **Every complexity oracle in this repository disagreed with the tool it cites** (`examples/ast-invariant-sentinel/`, `examples/polyglot-cst-parser/`, `examples/prompt-mutation-fuzzer/`): comprehensions and `match` contributed **zero**, so four functions passed the M≤10 gate at radon 11–13 and an eleven-case dispatcher measured 1. All three now count comprehension `for`/`if` clauses, `match` arms (wildcard excluded, guards not counted — measured against radon, not assumed), loop and `try` `else` clauses. `test_sentinel.py` carries a 19-case corpus asserting **agreement with radon** rather than restating the rules, plus one stated divergence: radon scores `except*` as zero because it predates PEP 654, so the gate is stricter there and never laxer anywhere. Nesting depth was blind to `match`/`case` and `TryStar` in both the sentinel and the CST parser — a six-deep function measured two. Fixing the measurement put five existing functions over the ceiling; all five are refactored, and the first one the corrected gate caught was the function implementing it.
- **The smell quantifier's ceilings are pylint's, and it counted differently** (`examples/code-smell-quantifier/smell_quantifier.py`): private and dunder methods counted against `max-public-methods` (R0904), `*args`/`**kwargs` against `max-args` (R0913), and the `def` node and docstring against `max-statements` (R0915). Real pylint reports nothing on all three fixtures; the quantifier gated on each. Its import graph also read `from pkg import b` as an import of `pkg` and never of `b`, so the commonest circular import in a package drew no edge at all — CPython refuses that program at runtime and this detector called it clean.
- **The documentation sanitizer called `0.0.0.0` a homelab leak** (`tools/doc_rules_structure.py`): `is_private` is the IANA not-globally-reachable set, not RFC 1918. The ranges a real private host answers on are now enumerated, and `endpoint: 0.0.0.0:4317` — copied from this repository's own collector config — is no longer a finding.
- **Model-ready extraction** (`examples/adaptive-web-crawler/markdown_extract.py`): the survey's top remaining gap, `llm_ready_output`, held by `crawl4ai` and `firecrawl`. The crawler's cleaner walked the document appending visible strings, so `<pre><code>` arrived as one unindented line with no language, hrefs were collected into a list with nothing joining them to their text and never resolved, and page text was emitted raw — a line beginning `#` became a heading in the prompt and a run of backticks closed the fence around it. **Output shaped for model consumption is output something downstream will parse**, which is the workflow `${{ }}` rule and the contract-rendering rule arriving a third time. Now: fences sized from the content (CommonMark closes on the first run of at least the opening length), links resolved against `<base href>` and inlined, chrome dropped by tag and ARIA landmark on a **stack rather than a counter** — a counter let `</a>` end a `<nav>` and emitted the rest of the menu as content — nested lists, blockquotes, alt text, a character budget that says when it truncated, and `no_content` / `no_main_region` warnings because an empty string and a page with nothing to say are the same value. The two invariants pulled against each other on the way: the `elif` ladder the tag handling started as breached the sentinel at complexity 16, and splitting every branch into a method breached the smell quantifier's God-class ceiling at 27 methods and 14 attributes — the second gate red on the change that made the first green. Resolved with a seam rather than a redistribution: `ChromeFilter`, `BlockBuilder` and `PageContext` take the responsibilities, and handlers are module-level functions in the dispatch table, leaving the parser six attributes and five methods. `HTMLContentCleaner` is deleted in the same commit that stops using it, per §7. The defect that cost the most: `HTMLParser` in CPython 3.14 keeps a private `self._pending` and its `close()` runs `self.rawdata += ''.join(self._pending)`, so an extractor using that name had its own output fed back through the parser as page text and escaped twice — `![alt](src)` rendered as `!\\[alt\\](src)`, with nothing failing and no traceback naming the collision. A test now asserts the set of attributes the subclass introduces beyond its base. 24 tests. Survey gaps 21 → 20.
- **A link inside backticks is not a link** (`tools/docs_validator.py`): the `link` rule scanned inline code spans, so any document *about* Markdown reported its own examples as broken — `[text](url)` in prose resolved `url` as a path and said it did not exist, which is what the crawler's new README hit on its first validation. Code spans are masked rather than deleted, so every other column stays where it was and a finding elsewhere on the line still points at the right place; an unclosed span is left alone rather than guessed at. The same lesson as the change above, inverted: escape on the way out, mask on the way in.
- **The trace generator spoke a private vocabulary in a standard envelope** (`examples/agent-telemetry-trace-generator/semconv.py`, `tools/semconv_snapshot.py`): it emitted valid OTLP carrying `ai.tokens.prompt`, `ai.model.name` and `agent.persona`, with every span kind hard-coded to `INTERNAL` and `gen_ai.response.finish_reasons` exported as the Python repr `"['stop']"` because the OTLP formatter had no `arrayValue` branch. Every collector accepted it and no GenAI-aware backend could chart it — a span with the wrong key is never rejected, it simply never appears in the dashboard built to read it. The survey ranked `semantic_conventions` first of twenty-two gaps, held by `openllmetry` and `openinference`. The convention is now **derived, not restated**: `semconv_snapshot.py` fetches the upstream model at a pinned commit, resolves its attribute groups and writes a snapshot the exhibit reads with nothing but the standard library; `generator.py --validate` prints the provenance beside the findings and the session validates with **0 errors**. Four things the exercise turned up, each pinned by a test: the GenAI conventions **moved repository** (`open-telemetry/semantic-conventions` now redirects to `semantic-conventions-genai`, which has no tagged release, so the pin is a commit); **"moved" is not "deprecated"** — every GenAI attribute is marked deprecated in the repository they left, and reading that table before the live registry reported all thirty conformant attributes on a correct span as obsolete; **a silent re-reference is not a requirement level** — `gen_ai.inference.client` re-references `gen_ai.operation.name` with no level purely to mark it sampling-relevant, and reading the silence as the default downgraded a **required** attribute to recommended; and a replacement pattern restricted to `gen_ai.*` choked on three OpenAI attributes, a partial pattern inside the module written to stop guessing. `ci.yml` verifies the snapshot offline. 34 tests. Survey gaps 22 → 21.
- **The sandbox certified a containment it was not applying** (`examples/ephemeral-container-sandbox/syscall_filter.py`): `CISPolicyAuditor` scored the *policy object*, so a default policy reported **100.0/100, 8/8, zero violations** — while the engine-less path, the one that runs whenever `docker` and `podman` are absent, enforced **none** of the eight. Verified by running it: the harness executed a payload that opened a socket, wrote a file into the invoking user's home directory and read its uid, exit 0, reported compliant. [Observation 11](./observations/systems/11-silent-certification-failure-and-gate-integrity.md) in the component whose entire job is containment.
